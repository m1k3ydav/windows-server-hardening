# Windows Server Hardening

A hands-on cybersecurity lab focused on securing a Windows Server environment hosted on AWS through system hardening, access management, and security monitoring.

## Tools & Technologies

- Windows Server
- Amazon Web Services (AWS)
- PowerShell
- Group Policy
- Windows Defender
- Windows Firewall
- DNS Manager

## Security Controls

- User account management and least privilege
- Password policies and access restrictions
- Security auditing and logon monitoring
- Endpoint protection and firewall configuration
- Automated security updates
- File and folder permissions
- Legacy protocol restrictions
- SMB encryption
- PowerShell script block logging
- DNS activity monitoring
